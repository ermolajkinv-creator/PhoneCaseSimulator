# Сигнал

Офлайн-игра на Kotlin про коллекцию из 66 150 телефонов и планшетов. Стартовый баланс — 47 500 игровых рублей. При обновлении один старый игровой жетон превращается в 190 рублей, чтобы сохранить покупательную способность относительно кейса «Классика». У каждого из трёх кейсов свои шансы выпадения. В любом кейсе шанс на Galaxy Z Fold8 Ultra равен 0,001 %, на Galaxy Z Fold8 — 0,0012 %, на iPhone Duo — 0,0015 %. За восстановление прошивки мастерская платит 900 игровых рублей. Повторы автоматически выкупаются за 45 % оценки с округлением вниз до 10 рублей.

В альбоме и на экране кейсов модели сгруппированы по редкости. Фильтр «Старые» показывает кнопочные телефоны, включая классические раскладушки и модели с физической клавиатурой. В группу «Субфлагманы» входят бывшие флагманы 2020–2023 годов и современные модели субфлагманских серий. У части архивных устройств год выпуска неизвестен. В «Раскладушках» собраны современные складные смартфоны. У трёх самых редких моделей сохранены индивидуальные шансы выпадения. В настройках владелец может войти в локальную админ-панель по паролю, начислить рубли или выдать выбранный телефон.

При запуске открывается главное меню с одной кнопкой «Кейсы». Внутри игры надпись «В меню» возвращает к нему.

Кейс открывается с анимацией прокрутки. Кнопка «Показать результат» пропускает её. На вкладке «Кейсы» хранится история последних 20 открытий. В карточке телефона можно нажать «Хочу в коллекцию» и найти его в альбоме через фильтр «Желания».

## Запуск

Откройте `android/src/main/assets/index.html` в современном браузере. Иллюстрации находятся в соседней папке `art/` и открываются вместе с карточками. Браузер хранит коллекцию и баланс локально. Android-приложение хранит собственный прогресс.

## Сборка Android

Для упаковки фотографий требуется Python 3. Откройте каталог проекта в Android Studio с установленной платформой Android SDK 35. Выберите модуль `android` и нажмите Run. Для сборки из терминала используйте JDK 17 и команду `./gradlew :android:assembleDebug`. APK появится в `android/build/outputs/apk/debug/`.

## Изменение игры

Игровая логика и интерфейс находятся в `src/Game.kt`. Первые 5000 моделей находятся в `src/Catalog.kt`, `src/AdditionalPhones.kt` и `src/CollectionExpansion.kt`, остальные записи — в `web/archive.tsv` в порядке номеров альбома. Источники фотографий — в `web/PHOTO-SOURCES.md`. Оформление находится в `web/style.css`, иллюстрации — в `android/src/main/assets/art`. Android запускает ту же Kotlin/JS-игру в локальном WebView.

После изменения игровой части укажите каталог компилятора Kotlin 2.1.21 в переменной `KOTLIN_HOME` и выполните `bash tools/build-web.sh`. Для упаковки HTML скрипту нужен Python 3. Для автономной браузерной версии передайте скрипту `--standalone Signal.html`. Затем пересоберите Android-приложение.

## Компактный APK

Для компактного релиза запустите `tools/build-web.sh --compact` с Python 3, Pillow и указанным выше компилятором Kotlin. Затем выполните `./gradlew :android:assembleDebug -PcompactArt=true`. Уменьшенные фотографии работают без интернета.


## Лёгкая загрузка для Android

В лёгком APK находятся весь каталог, оформление кейсов и стартовый набор фотографий. Остальные фотографии приложение получает с GitHub при первом просмотре. Перед сохранением в кеш приложение сверяет контрольную сумму снимка с каталогом. Пока Android хранит кеш, просмотренные снимки открываются без интернета. В полном APK все фотографии доступны сразу.

Для сборки лёгкой версии сначала выполните обычную сборку веб-части, затем `python3 tools/build-light.py` и `./gradlew :android:assembleDebug -PlightArt=true`. Подпись и идентификатор приложения у вариантов одного релиза должны совпадать, чтобы игрок мог обновиться и сохранить коллекцию.
