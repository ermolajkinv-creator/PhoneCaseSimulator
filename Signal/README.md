# Сигнал

Офлайн-игра на Kotlin про коллекцию из 5000 телефонов и планшетов. Начальный баланс — 250 монет. У каждого из трёх кейсов свои шансы выпадения. В любом кейсе шанс на Galaxy Z Fold8 Ultra равен 0,005 %, на Galaxy Z Fold8 — 0,01 %, на iPhone Duo — 0,012 %. За каждую восстановленную прошивку мастерская платит 80 монет. Повторные модели автоматически обмениваются на монеты.

В альбоме и на главной модели сгруппированы по редкости. Фильтр «Старые» показывает кнопочные телефоны, включая классические раскладушки и модели с физической клавиатурой. В «Раскладушках» собраны современные складные смартфоны. У трёх самых редких моделей сохранены индивидуальные шансы выпадения. В настройках владелец может войти в локальную админ-панель по паролю, начислить монеты или выдать выбранный телефон.

## Запуск

Откройте `android/src/main/assets/index.html` в современном браузере. В файле уже есть игра и все иллюстрации. Браузер хранит коллекцию и баланс локально. Android-приложение хранит собственный прогресс.

## Сборка Android

Откройте каталог проекта в Android Studio с установленной платформой Android SDK 35. Выберите модуль `android` и нажмите Run. Для сборки из терминала используйте JDK 17 и команду `./gradlew :android:assembleDebug`. APK появится в `android/build/outputs/apk/debug/`.

## Изменение игры

Игровая логика и интерфейс находятся в `src/Game.kt`. Список моделей находится в `src/Catalog.kt`, `src/AdditionalPhones.kt` и `src/CollectionExpansion.kt`, источники фотографий — в `web/PHOTO-SOURCES.md`. Оформление находится в `web/style.css`, иллюстрации — в `web/art`. Android запускает ту же Kotlin/JS-игру в локальном WebView.

После изменения игровой части укажите каталог компилятора Kotlin 2.1.21 в переменной `KOTLIN_HOME` и выполните `bash tools/build-web.sh`. Для упаковки HTML скрипту нужен Python 3. Затем пересоберите Android-приложение.

## Компактный APK

Для компактного релиза запустите `tools/build-web.sh --compact` с Python 3, Pillow и указанным выше компилятором Kotlin. Затем соберите APK обычным способом. Уменьшенные фотографии работают без интернета.
