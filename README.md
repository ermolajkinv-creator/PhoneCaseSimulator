# Phone Case Simulator

Офлайн-игра для Android 8.0+ (minSdk 26): неоновые карточки, открытие кейса,
коллекция, продажа телефонов и бесплатные монеты в магазине. Без разрешений,
рекламы, сетевого доступа и платежей. Прогресс хранится в приватных preferences.
Не удаляйте данные приложения: это удалит локальный прогресс.

## APK

В GitHub откройте **Actions → Build Android APK → успешный запуск →
Artifacts → PhoneCaseSimulator-APK**. Распакуйте ZIP и установите `app-debug.apk`.
Это подписанная debug-сборка для демонстрации, не релиз для Google Play.
Разрешите установку из выбранного источника в настройках Android. Для обновления
нужна одинаковая подпись; debug-ключ CI может меняться между запусками. Если
Android сообщает о несовпадении подписи, не удаляйте приложение без резервной
копии прогресса. Для постоянных обновлений нужен отдельный стабильный release-ключ.

## Сборка и проверки

JDK 17, Gradle **8.11.1**, Android SDK 35 и build-tools 35.0.0.
Gradle Wrapper в исходном проекте отсутствует; CI устанавливает указанную версию
через `gradle/actions/setup-gradle`.

```sh
gradle --no-daemon testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
gradle --no-daemon connectedDebugAndroidTest
```

Вторая команда требует подключённого устройства/эмулятора. CI проверяет подпись
APK и minSdk, публикует отчёты и запускает тесты установки/старта, открытия кейса,
сохранения при пересоздании Activity, магазина и чтения старой коллекции на
эмуляторах API 26, 33, 34, 35, 36 и 37. Если публичного образа API 37 нет,
соответствующая проверка явно сообщает **NOT TESTED**, а не подтверждает совместимость.

## Версия 1.2: Prism UI, справочник и админ-панель

Интерфейс оформлен по визуальному референсу: сине-фиолетово-розовый градиент,
полупрозрачные скруглённые панели, светлая типографика и строки характеристик.
Каталог расширен до 40 моделей. Первые шесть индексов сохранены для совместимости
со старыми коллекциями. В справочнике есть поиск по названию, чипсету, системе
и редкости, характеристики, описание и число экземпляров в коллекции.
Характеристики относятся к указанному варианту и ОС при выпуске. Исправлена
ошибочная пометка Z Fold 8 Ultra как вымышленного: это реальная модель Samsung.
Версия 1.3 добавляет OnePlus 15, OnePlus 13, Fold8, Flip8 и другие модели,
сохраняя индексы всех прежних телефонов, суммарные шансы редкостей и 0,1% для Ultra.

Источники для новых флагманов:
- [Samsung: Galaxy Z Fold8 Ultra, Fold8, Flip8 и таблица характеристик](https://news.samsung.com/us/samsung-galaxy-z-fold8-ultra-fold8-flip8-foldables-perfected-every-way-of-living/)
- [OnePlus 15: официальные характеристики](https://www.oneplus.com/us/15/specs)

Общие названия старых моделей не являются точными спецификациями отдельного поколения.

Кнопка «Админ-панель» открывает ввод пароля. После входа можно бесплатно выдавать
любую модель, включая ультралегендарную, без списания монет. Выдача сохраняется
тем же способом, что и открытие кейса. При уходе в фон или пересоздании Activity
нужно войти повторно; пароль и сессия не записываются в состояние экрана.
В APK хранится SHA-256 проверочного пароля. Это локальная блокировка игровой
функции, не защита от анализа APK или изменения локального приложения.

## Совместимость и пределы проверки

Сохранён minSdk 26, compileSdk/targetSdk 35. Java и Kotlin используют JVM target 17.
Причина исходного падения Actions: Java target 1.8 и Kotlin target 17
(`:app:compileDebugKotlin`, запуск 41498840490).
Используются только платформенные Android API; сторонних native-библиотек нет.
Учтены system bars/cutout для edge-to-edge Android 15+, масштабирование текста,
поворот экрана и изменение размера окна. Нет фиксированной ориентации.

| Запрошенная система | Автоматическая проверка |
| --- | --- |
| HyperOS 1 / Android 13–14 | AOSP/Google emulator API 33–34 |
| MagicOS 9 / Android 15 | AOSP/Google emulator API 35 |
| XOS 16 / Android 16 | AOSP/Google emulator API 36 |
| One UI 9 / Android 17 | API 37, только если доступен образ |

Эмуляторы Google не проверяют особенности HyperOS, MagicOS, XOS или One UI.
Названия/соответствие версий оболочек указаны по требованиям, а не по результатам
проверки производителей. Тестирования на реальных устройствах не проводилось.
Установка и UI на Android 16/17 требуют успешного соответствующего CI-теста;
одного targetSdk недостаточно для заявления о совместимости.

На реальных устройствах проверьте: установку APK, жестовую и трёхкнопочную
навигацию, вырезы экрана, крупный шрифт, поворот/складной экран, открытие при
отключённых системных анимациях, уход в фон во время открытия, перезапуск
процесса, продажу дубликата и сохранение монет/коллекции после обновления.

Локальная среда Codex: JDK 21 есть; Gradle, Android SDK, adb и эмулятора нет.
Попытка сборки завершилась `gradle: command not found`. Загрузка инструментов
через HTTPS невозможна из-за `Failed to connect to proxy port 8080`.
Фактический статус удалённых проверок смотрите в PR/Actions; конфигурация CI сама
по себе не означает успешного прохождения тестов.
