# Phone Case Simulator

Офлайн-игра для Android 8.0+ (minSdk 26): неоновые карточки, открытие кейса,
коллекция, продажа телефонов и бесплатные монеты в магазине. Без разрешений,
рекламы, сетевого доступа и платежей. Прогресс хранится в приватных preferences.
Не удаляйте данные приложения: это удалит локальный прогресс.

## APK

В GitHub откройте **Actions → Build Android APK → успешный запуск →
Artifacts → PhoneCaseSimulator-APK**. Распакуйте ZIP и установите `app-debug.apk`.
Это подписанная debug-сборка для демонстрации, не релиз для Google Play.
Разрешите установку из выбранного источника в настройках Android. Для обновления
нужна одинаковая подпись; debug-ключ CI может меняться между запусками. Если
Android сообщает о несовпадении подписи, не удаляйте приложение без резервной
копии прогресса. Для постоянных обновлений нужен отдельный стабильный release-ключ.

## Сборка и проверки

JDK 17, Gradle **8.11.1**, Android SDK 35 и build-tools 35.0.0.
Gradle Wrapper в исходном проекте отсутствует; CI устанавливает указанную версию
через `gradle/actions/setup-gradle`.

```sh
gradle --no-daemon testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
gradle --no-daemon connectedDebugAndroidTest
```

Вторая команда требует подключённого устройства/эмулятора. CI проверяет подпись
APK и minSdk, публикует отчёты и запускает тесты установки/старта, открытия кейса,
сохранения при пересоздании Activity, магазина и чтения старой коллекции на
эмуляторах API 26, 33, 34, 35, 36 и 37. Если публичного образа API 37 нет,
соответствующая проверка явно сообщает **NOT TESTED**, а не подтверждает совместимость.

## Совместимость и пределы проверки

Сохранён minSdk 26, compileSdk/targetSdk 35. Java и Kotlin используют JVM target 17.
Причина исходного падения Actions: Java target 1.8 и Kotlin target 17
(`:app:compileDebugKotlin`, запуск 41498840490).
Используются только платформенные Android API; сторонних native-библиотек нет.
Учтены system bars/cutout для edge-to-edge Android 15+, масштабирование текста,
поворот экрана и изменение размера окна. Нет фиксированной ориентации.

| Запрошенная система | Автоматическая проверка |
| --- | --- |
| HyperOS 1 / Android 13–14 | AOSP/Google emulator API 33–34 |
| MagicOS 9 / Android 15 | AOSP/Google emulator API 35 |
| XOS 16 / Android 16 | AOSP/Google emulator API 36 |
| One UI 9 / Android 17 | API 37, только если доступен образ |

Эмуляторы Google не проверяют особенности HyperOS, MagicOS, XOS или One UI.
Названия/соответствие версий оболочек указаны по требованиям, а не по результатам
проверки производителей. Тестирования на реальных устройствах не проводилось.
Установка и UI на Android 16/17 требуют успешного соответствующего CI-теста;
одного targetSdk недостаточно для заявления о совместимости.

На реальных устройствах проверьте: установку APK, жестовую и трёхкнопочную
навигацию, вырезы экрана, крупный шрифт, поворот/складной экран, открытие при
отключённых системных анимациях, уход в фон во время открытия, перезапуск
процесса, продажу дубликата и сохранение монет/коллекции после обновления.

Локальная среда Codex: JDK 21 есть; Gradle, Android SDK, adb и эмулятора нет.
Попытка сборки завершилась `gradle: command not found`. Загрузка инструментов
через HTTPS невозможна из-за `Failed to connect to proxy port 8080`.
Фактический статус удалённых проверок смотрите в PR/Actions; конфигурация CI сама
по себе не означает успешного прохождения тестов.

## Исправление экономики 2.5.1

Стоимость каждого кейса автоматически рассчитывается из всех 1000 исходов:
115% средней цены продажи награды с округлением вверх до 1000 ₽.
Текущий прайс: 31 000 / 45 000 / 55 000 / 97 000 ₽.
Это устраняет гарантированно дешёвую покупку дорогих наград; отдельный результат
может быть дороже или дешевле кейса. Шансы, включая Ultra 0,1%, не изменены.
Новым игрокам — 62 000 ₽, повторяемый бесплатный бонус — 31 000 ₽.
Существующие балансы, коллекции, рынок и прошивки сохраняются без пересчёта.
Старые записи о стоимости кейсов/бонуса выше относятся к предыдущим версиям.

## Подарок при нехватке денег — 2.5.2

Если текущего баланса не хватает ни на один кейс и ни на одно непроданное
объявление сегодняшнего рынка, на экранах появляется подарок 31 000 ₽.
Телефоны продавать ради получения подарка не требуется. После получения денег
хватает на классический кейс, поэтому кнопка исчезает. Если баланс снова
опустится ниже всех доступных покупок, подарок снова доступен. Повторное
нажатие проверяет актуальный баланс: безусловного повторного начисления нет.
Деньги и вся коллекция сохраняются вместе до обновления экрана. Во время
анимации открытия кнопка не показывается; после завершения она доступна.

## Перезарядка подарка — 2.5.3

После любого бесплатного начисления действует общая перезарядка 10 минут:
и для помощи при бедности, и для бонуса в магазине. Трата денег до нуля не
сбрасывает таймер. Время получения сохраняется атомарно вместе с балансом;
перезапуск приложения и пересоздание экрана не дают получить подарок снова.
На экране показан обратный отсчёт. Старые сохранения без lastGiftAt получают
нулевую перезарядку. Таймер использует системные часы; это офлайн-механика,
не серверная защита от изменения часов или файлов сохранения.

## Версия 2.6 — функции по семи скриншотам

Добавлена собственная реализация общих идей интерфейса: постоянные нижние вкладки

APK референса не запускался. Его основной HTML и config — контейнеры ENCF;

Чужие код, иллюстрации, названия вымышленных моделей и баннеры не переносились.

Ежедневная награда: один раз за день UTC, серия до семи дней, от 31 000 до
61 000 ₽, пропуск сбрасывает серию. Это отдельная ограниченная награда, не
обход 10-минутного таймера подарка/магазина (их lastGiftAt не изменяется).
Офлайн-часы не являются серверной защитой от редактирования времени.
Кликер начисляет 10 ₽ и сохраняет каждый клик; фонового начисления нет.

Апгрейдер расходует один обычный экземпляр выбранной модели из owned, при успехе
выдаёт одну более дорогую цель; при неудаче награда отсутствует. Деньги не
списываются. Вероятность в тысячных: floor(750 × цена исходного / цена цели),
с минимумом 1 и максимумом 750; показывается до попытки. Used-инвентарь не
расходуется. Ultra запрещена как цель, её шансы в кейсах не изменены.

Профиль: редактируемое имя, состояние коллекции по редкостям, избранное, число
нажатий, кейсы с версии 2.6 и шесть сохраняемых достижений. Старый неизвестный
счётчик открытых/проданных телефонов не выдумывается. Покупки, коллекция,
прошивки, баланс и таймер подарка совместимы с предыдущими сохранениями.
Battle Pass, сетевые таблицы рекордов, питомцы и сезонные баннеры не добавлялись.

## Версия 2.6.1

Админ-панель: произвольное начисление и кнопка максимального баланса. Ввод
проверяется, доступ только после пароля; баланс ограничен Int.MAX_VALUE

Награды отдельные, не обнуляют lastGiftAt и его 10-минутную перезарядку.

## Версия 2.7 — посетители сервиса и развитие мастерской

Игровые NPC приходят каждые 120 секунд; видны до трёх последних предложений.
Один заказ одновременно: ремонт экрана, настройка, Android-кастом или джейлбрейк
iPhone. Предложения детерминированы временным слотом; обновление экрана не даёт
новых заказов. Модель телефона соответствует платформе задания.

При принятии списывается показанная цена деталей, работа длится 10–60 секунд.
Оплата выдаётся только после завершения и нажатия «Выдать телефон». Заказ,
таймер, списание/выплата и история последних слотов сохраняются с прогрессом;
повторная выдача и повторное принятие завершённого предложения запрещены.
Чужой телефон не добавляется в инвентарь и не расходует коллекцию игрока.
Ни реальные прошивки, ни реальный ремонт не выполняются.

Пять уровней сервиса. Уровень 2 открывает кастомы, уровень 3 — джейлбрейк.
Улучшения: 10k/30k/60k/120k ₽ и репутация 3/10/25/50; выполненный заказ даёт
+1 репутации. Уровень повышает гонорар и сокращает время. История клиентов и
репутация видны в профиле. Офлайн-часы не являются серверной античит-защитой.

## Версия 3.0 — десять функций

1. Магазин новых телефонов в каталоге: цена 110% оценки, Ultra исключена.
2. Торг на рынке: одна попытка на объявление, шанс 60%, скидка 15%, без
   перезапуска попытки при повторном нажатии; последние 200 попыток сохраняются.

4. Однократные денежные награды за шесть достижений.
5. Контракт: три новых телефона одной редкости в случайный следующей; от
   обычных до эпических включительно, Ultra исключена. Доплата доводит стоимость

   Исходные модели и доплата видны до подтверждения. Б/у телефоны не расходуются.
6. Ежедневный заказ на закупку определённой новой модели за 125% оценки +2500 ₽.
   Один за день UTC, использованный телефон изымается, повторная выдача запрещена.
7. Доход сервисного центра: после активации 100 ₽/мин за текущий уровень,
   только полные минуты, максимум накопления 120 минут. После сбора новый отсчёт.
8. Сейф без процентов: отдельный баланс, переводы в обе стороны с проверкой
   лимитов; лимит каждого счёта Int.MAX_VALUE, переполнения нет.
9. Статистика движения денег с версии 3.0 и последние 50 операций. Переводы
   в сейф исключены из доходов/расходов. Коллекция не оценивается как прибыль.
10. Одна локальная резервная копия в данных приложения, с подтверждением замены
    и восстановления. Это не внешний файл: удаление данных удалит и копию.
    Восстановление не откатывает lastGiftAt и отметки ограниченных выплат,
    ежедневные задания/награды и завершённые клиентские предложения. Копия
    предназначена для восстановления игрового прогресса, не для серверной защиты.

## Версия 3.0.1 — 500 телефонов

Добавлены ровно 400 отдельных моделей (индексы 100–499). Первые 100 моделей
не переставлены: коллекция, избранное, б/у и профили прошивок старых сохранений
продолжают ссылаться на те же телефоны. В расширении есть Samsung, Xiaomi,
Redmi, POCO, iPhone, Google Nexus/Pixel, OnePlus, HONOR, HUAWEI, realme, OPPO,
vivo, Motorola, Sony, ASUS, Nokia, Infinix, TECNO и ZTE. Модели разных лет,
без размножения по цветам и объёму памяти; указаны год, чип, экран и ОС
при выпуске. Региональные варианты могут отличаться. Цены — игровые оценки,
рисунки стилизованы; это не каталог фотографий и не актуальный прайс магазинов.

Все 500 моделей имеют ненулевой шанс в классическом кейсе и доступны в
энциклопедии, админ-панели и коллекции. Новые модели также доступны для покупки,
на рынке и в совместимых механиках мастерской. Доли редкостей классического
кейса сохранены: 50% / 28% / 15% / 5,8% / 1,1% / 0,1%. Новых Ultra нет;
Fold 8 Ultra по-прежнему занимает ровно один из 1000 билетов каждого кейса.
Цены кейсов автоматически пересчитаны по расширенному пулу: 25 000 / 39 000 /
54 000 / 91 000 ₽. Стартовый баланс 62 000 ₽ и подарок 31 000 ₽ сохранены.

Каталог, коллекция, энциклопедия и выдача в админ-панели загружают по 32 модели
через «Показать ещё»; поиск охватывает весь каталог. Для выдачи добавлен поиск.
Идентификатор рыночного объявления теперь включает модель и состояние, чтобы
после расширения каталога скидка от старого предложения не досталась другому
телефону. Предложения текущего дня могут обновиться; купленные экземпляры
в коллекции сохраняются.

Проверки фиксируют порядок первых 100 названий контрольной суммой, перебирают
все 1000 исходов и проверяют доступность каждой из 500 моделей, покупку новых
моделей и восстановление новых индексов. Сценарий эмулятора проверяет порционную
загрузку, поиск последней модели, её покупку, сохранение и страницу справочника.
minSdk 26 сохранён. Реальные устройства и OEM-оболочки не тестировались;
Android 17 проверяется только при наличии образа API 37 в CI.

## Версия 3.0.2 — пауза кликера

Не более 12 принятых нажатий за любое скользящее окно в 1000 мс. Тринадцатое
в этом окне включает блокировку на 30 секунд и не выдаёт награду. Во время
блокировки баланс, число кликов и дневное задание не увеличиваются; повторные
нажатия не продлевают срок. После истечения паузы кнопка включается автоматически,
на экране есть обратный отсчёт. Обычные нажатия оплачиваются по-прежнему: 10 ₽.

Последние нажатия и срок блокировки сохраняются вместе с прогрессом. Переход
между экранами, пересоздание Activity, перезапуск приложения и восстановление
локальной копии не сбрасывают текущую защиту. Старые сохранения получают пустое
окно без штрафа. Это локальный лимит частоты с часами устройства, не серверное
распознавание автокликеров: более медленные автоматические нажатия он не отличает
от ручных. Проверены границы окна/паузы, отсутствие награды при блокировке,
сохранение защиты, восстановление копии и автоматическое включение кнопки.
